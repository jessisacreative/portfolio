# Jess Watson / @jessisacreative — Website redesign concept

Status: **working first draft, not published**. The current public homepage and portfolio pages have not been replaced.

## The idea

An editorial, multidisciplinary portfolio that brings together campaigns, design, independent photography, published writing and creative experiments. The aim is to feel more like Jess's wider creative practice without losing professional credibility.

Open the new file at: concept/index.html

## What changes

- Lead with Jess Watson and @jessisacreative rather than a single job title.
- Make the professional work prominent, but give personal interests and photography their own spaces.
- Warm paper palette, oversized expressive typography, dark editorial section, lime and coral accents.
- Keep the proposed 3D portfolio world as a future Playground feature, not a blocker for launch.
- Responsive design, alt text, visible keyboard focus, reduced-motion support and working project filters.

## What works already

- Six selected projects now link to newly redesigned case-study pages that preserve the existing project descriptions, roles, images and captions.
- Category filters work with mouse, touch and keyboard.
- The journal links to the real published Ozzy / Black Sabbath article.
- Email and social links use existing published contact details.
- Homepage includes title, meta description, social tags and Person structured data.
- Existing repository image assets have been verified to exist.

## What is still a draft

- All six featured case studies are now redesigned and included in this draft. Other projects from the original website remain available on the live site and can be migrated later.
- Photography now brings together original live music work, fine-art nature studies, fungi exhibition work and event documentation. Jess's original fine-art images are credited, resized to WebP and kept under 700px on the longest edge for faster loading.
- The journal links to one verified published article; additional writing will be added when there are more confirmed public pieces.
- The Playground is a labelled concept rather than a functioning interactive environment.
- Search Console, canonical URLs, redirects and a production sitemap are launch tasks, not completed work.

## How to request changes

No code editing is required. Describe a change in ordinary words, e.g. “less corporate”, “make photography bigger”, or “move the journal higher”; the concept can be revised for you.

## Publication safety

This is a draft in a separate GitHub branch. It contains the editorial homepage, six consistent case studies, and a shared stylesheet. Merging and publishing must be a distinct later decision.
